# Campus Hub

Student Resource Sharing and Collaboration System
Full Stack Java Capstone Mini Project

Tech: React (frontend), Spring Boot (backend), MySQL (database)

## Run Backend
1. Start MySQL
2. In backend/src/main/resources/application.properties set your MySQL password
3. Open the backend folder in VS Code and run CampusHubApplication
Backend runs on http://localhost:8080

## Run Frontend
1. Open the frontend folder in terminal
2. npm install
3. npm run dev
Frontend runs on http://localhost:5173
